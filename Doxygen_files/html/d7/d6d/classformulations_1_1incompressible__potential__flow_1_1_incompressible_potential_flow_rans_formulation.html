Incompressible potential flow rans formulation.

This RansFormulation solves incompressible potential flow equation for steady state problems. (The dof is KratosRANS.VELOCITY_POTENTIAL) Afterwards, Kratos.VELOCITY variable is updated properly from computed KratosRANS.VELOCITY_POTENTIAL values for each node.

This does not support periodic conditions.

Args: model_part (Kratos.ModelPart): ModelPart to be used in the formulation. settings (Kratos.Parameters): Settings to be used in the formulation.
