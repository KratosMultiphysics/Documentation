Calculates the value of the response.

This method updates the design with the provided control field. If a control field is updated which affects the this response value, then a new value is computed. Otherwise, the previous value is returned.

Args: control_field (KratosOA.CollectiveExpression): Control field of the new design.

Returns: float: Respone value.
