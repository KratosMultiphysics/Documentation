Detailed Description

The base class for mesh motion solvers.

This class defines the user interface to mesh motion solvers.

Derived classes must override the function _CreateSolutionStrategy() to customize the mesh motion algorithm. The mesh motion solving strategy and linear solver should always be retrieved using the getter functions. Only the member variables listed below should be accessed directly.

Public member variables: settings – Kratos parameters for general mesh motion settings. mesh_model_part – the mesh motion model part.
