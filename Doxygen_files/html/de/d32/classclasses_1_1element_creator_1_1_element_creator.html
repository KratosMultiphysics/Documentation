Detailed Description

Extends KratosClassCreator for a Kratos Element.

It expects a element_template.cpp and element_template.h as base file.

Input

  • name: string name of the class
  • base: string name of the base element, if any. Defaults to 'Element'.
  • template:: instance of KratosTemplate not yet implemented.
  • members: list of KratosClassMember class members to be added.
  • procedures: list of KratosClassProcedures class procedures to be added. NYI

Output

  • Instance of a KratosElementCreator

Rules

  • KRATOS_CLASS_LOCAL_FLAGS}: The flag list
  • KRATOS_ELEMENT_LIST_DOFS}: The dof list
  • KRATOS_ELEMENT_EQUATION_ID_DOFS}: The dof list for the equation id's
