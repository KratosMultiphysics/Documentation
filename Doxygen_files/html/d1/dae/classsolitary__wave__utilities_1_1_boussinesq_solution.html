Detailed Description

Analytical solution for a solitary wave with the modified Boussinesq equations.

G. Wei and J. T. Kirby, Time-dependent numerical Code for extended Boussinesq equations. Journal of Waterway, Port, Coastal and Ocean Engineering, September 1995

O. Nwogu, Alternative form of Boussinesq for nearshore wave propagation. Journal of Waterway, Port, Coastal and Ocean Engineering, 1993
