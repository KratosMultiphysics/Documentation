Detailed Description

template<class TPointType>
class Kratos::Quadrilateral2D8< TPointType >

A eight node 2D quadrilateral geometry with quadratic shape functions.

While the shape functions are only defined in 2D it is possible to define an arbitrary orientation in space. Thus it can be used for defining surfaces on 3D elements. The node ordering corresponds with: 3--—6--—2 | | | | 7 5 | | | | 0--—4--—1
