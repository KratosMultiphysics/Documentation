Detailed Description

The structural mechanics contact explicit dynamic solver.

This class creates the mechanical solvers for contact explicit dynamic analysis. It currently supports central difference method

Public member variables: dynamic_settings – settings for the explicit dynamic solvers.

See structural_mechanics_solver.py for more information.
