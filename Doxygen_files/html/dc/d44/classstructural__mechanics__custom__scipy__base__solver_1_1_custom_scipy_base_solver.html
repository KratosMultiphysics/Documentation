Detailed Description

The structural mechanics custom scipy base solver.

This class creates the mechanical solvers to provide mass and stiffness matrices as scipy matrices.

Derived class must override the function SolveSolutionStep. In there the Mass and Stiffness matrices can be obtained as scipy matrices. The computation of the eigenvalue problem in this implementation is only an example how this solver is to be used.

See structural_mechanics_solver.py for more information.
