Detailed Description

This class is used in order to compute the a mortar mesh tying formulation.

This class constructs the model parts containing the mesh tying conditions and initializes parameters and variables related with the mesh tying. The class creates search utilities to be used to create the tying pairs

Only the member variables listed below should be accessed directly.

Public member variables: Model – the model used to construct the process. settings – Kratos parameters containing solver settings.
