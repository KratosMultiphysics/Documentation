This process sets wall function parameters.

This process is used to activate wall function in wall conditions by setting RANS_IS_WALL_FUNCTION_ACTIVE to 1 in conditions. Additionally it also sets STRUCTURE and SLIP flag on the same nodes as well as conditions in same model part.

Currently, all the wall conditions should be in one model part/sub model part. Having wall conditions in more than one model part/sub model part is not allowed.
