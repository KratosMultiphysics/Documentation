Detailed Description

Multistage orchestrator to sequentially execute a collection of stages.

This multistage orchestrator executes the different stages sequentially (i.e. one after the other). The execution order is specified by the 'execution_list' in the input settings. The save and load (aka checkpointing) is executed between stages.

Member variables: _execution_list – list containing the names of the stages to be executed _stages_to_checkpoint_list – list containing the names of the stages to be checkpointed (saved)
