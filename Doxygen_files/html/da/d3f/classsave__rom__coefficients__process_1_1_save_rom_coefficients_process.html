Append the current ROM state's generalized coordinates (q) to the historical snapshots list.

If 'snapshot_solution_type' is set to 'total', the cumulative sum of q is saved, representing the total solution up to the current time step. If 'snapshot_solution_type' is 'incremental', only the solution increment (Δq) for the current time step is saved.
