◆ create_xml_element()

core.xdmf.UniformGrid.create_xml_element (   self)

Return the XDMF item as an XML element node in the XML document tree.

If the node is the root element of the XML document, it can be written to a file as:

root = obj.create_xml_element() ElementTree(root).write(file_or_filename)

If it is a child node, it can be appended to its parent as:

child = obj.create_xml_element() parent.append(child)

An entire XML document representing an XDMF model is built from a set of XdmfItem objects by combining their XML nodes in an XML tree.

Reimplemented from core.xdmf.XdmfItem.
