Detailed Description

This is the to apply rotation to a given modelpart.

The class applies a rotation to a given modelpart given a constant angular velocity or it calculates the torque applied on the modelpart and calculates(by BDF2 time integration) the current theta and omega and rotates the modelpart accordingly.
