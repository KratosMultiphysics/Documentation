Detailed Description

This class is used in order to compute the contact using a mortar MPC formulation.

This class constructs the model parts containing the contact conditions and initializes parameters and variables related with the contact. The class creates search utilities to be used to create the contact pairs

Only the member variables listed below should be accessed directly.

Public member variables: Model – the container of the different model parts. settings – Kratos parameters containing solver settings.
