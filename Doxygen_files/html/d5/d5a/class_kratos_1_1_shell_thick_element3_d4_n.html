Detailed Description

template<ShellKinematics TKinematics>
class Kratos::ShellThickElement3D4N< TKinematics >

ShellThickElement3D4N.

This element represents a 4-node bilinear Shell element based on the Enhanced Assumed Strain Method (E.A.S.) for the membrane part and on the Mixed Interpolation of Tensorial Components (M.I.T.C.) for the trasverse shear part. This element is formulated for small strains, but can be used in Geometrically nonlinear problems involving large displacements and rotations using a Corotational Coordinate Transformation. Material nonlinearity is handled by means of the cross section object.
