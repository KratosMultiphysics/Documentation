Detailed Description

This class is a base class used to perform the search for contact and mesh tying.

This class constructs the model parts containing the conditions. The class creates search utilities to be used to create the pairs

Only the member variables listed below should be accessed directly.

Public member variables: Model – the container of the different model parts. settings – Kratos parameters containing solver settings.
