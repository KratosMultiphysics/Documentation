Detailed Description

A helper class for identifying the cell/element topology type.

Attributes: attrib – dictionary of XML attributes specifying the cell type.

Example: triangle = TopologyCellType(dim=2, num_points=3) print(triangle.attrib["TopologyType"]) # "Triangle"
